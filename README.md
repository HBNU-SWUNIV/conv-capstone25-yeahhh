## <u>Teamate</u> Project Background
- ### 필요성
  - 현대 기업과 기관에서는 다양한 자산(노트북, 데스크탑, 소모품, 주변기기 등)을 효율적으로 관리하는 것이 매우 중요하다. 특히 자산의 정확한 등록, 이동, 사용, 재고 현황을 실시간으로 파악하지 못할 경우, 업무 효율 저하, 재정 손실, 책임 소재 불분명 등의 문제가 발생할 수 있기에 자산관리프로그램은 필요하다.
- ### 기존 해결책의 문제점
  - 팀원 중 한 명이 최근 2주간 해외인턴십 경험을 통해 자산 관리 시스템을 직접 만들어보며 자산 등록, 이동 추적, 알림 및 통지 기능을 수행해보았지만, 모든 기능을 구현하기에는 시간과 지식이 부족하였다. 백엔드, 프론트엔드, UI/UX 디자인, 데이터베이스 관리 등 다양한 기술적 요소에 대한 경험과 지식이 충분하지 않아, 시스템을 완전히 구현하고 최적화하는 데 한계가 있었다.따라서 이번 과제에서는 한 학기라는 충분한 기간을 활용하여 이전 경험에서 부족했던 부분을 보완하고, 새로운 자산 관리의 전 과정을 통합한 웹 시스템을 구축하고자 한다.
  
## System Design
1) 자산 등록 및 마스터 데이터
각 자신을 고유하게 식벽하고 설명하기 위한 핵심 정보 :
자산 ID / 태그 번호 (자동 생성 또는 수동 입력)
자산 유형 (예: 노트북, 데스크탑, 토너, 프로젝터)
자산 카테고리 (IT 하드웨어, 소모품, 주변기기)
브랜드 및 모델
일련 번호
구매일
공급업체 / 벤더
구매 주문서 / 송장 번호
보증 시작 및 종료일
위치 (캠퍼스, 건물, 방)
배정된 부서 / 학부
관리인 / 책임자
상태 (활성, 사용 중, 보관 중, 유지보수 중, 폐기됨)
감가상각 / 장부가 (선택 사항, 재무 통합용)

2) 자산 이동 추적
자산이 반출·반입될 때를 추적하기 위한 항목:
이동 ID
자산 ID / 태그
이동 유형 (반출 / 반입 / 이전)
반출일
예정 반납일
실제 반납일
자산을 사용하는 사람 (직원/학생 이름, ID)
학부 / 부서
사용 목적 / 비고
승인 상태 (승인이 필요한 경우)
반출 / 반입 시 자산 상태

3) 알림 및 통지 규칙
연체 반납 알림
트리거: 자산이 X일 이내에 반납되지 않은 경우 (설정 가능, 기본 5일)
알림 대상: 관리인, 자산 관리자, 요청자
포함 내용: 자산 세부 정보, 반출일, 책임자
재고 부족 알림
트리거: 재고 수량이 최소 임계값에 도달할 때 (자산 유형별로 설정 가능)
적용 대상: 토너, 케이블, 어댑터 등 소모품
알림 대상: 구매 담당자 / 창고 관리자

4) 소모품 지금
사용자에게 지급된 품목을 추적하기 위한 항목:
거래 ID
품목명
품목 코드
지급 수량
지급일
수령인 이름 / ID
학부 / 부서
잔여 재고 수량
재고 재주문 수준 (최소 임계값)
승인 상태 (필요한 경우)

5) 재고 관리
카테고리별 재고 목록
현재 수량
재주문 수준
공급업체 정보
구매 이력

6) 설정가능항목
반납 기한 일수 (기본값: 5일)
품목 유형별 재주문 수준
알림 수신자
승인 워크플로우 설정
사용자 역할 권한 (관리자, 관리인, 부서 사용자
    
## Conclusion
  - 기대효과 :
      업무 효율성 향상: 자산 등록, 이동 추적, 재고 관리, 소모품 지급 등 모든 자산 관리 기능을 웹 기반으로 통합함으로써, 관리자의 반복적인 수작업을 최소화하고 실시간 정보 확인이 가능하다.
      데이터 기반 의사결정 지원: 자산 현황, 재고 수준, 반납 연체 등 데이터를 시각화하고 알림 기능을 제공하여, 관리자가 빠르고 정확하게 의사결정을 내릴 수 있다.
      책임 소재 명확화: 자산 이동 및 사용 내역이 기록되고 승인 워크플로우가 적용되어, 분실·손상 시 책임 소재를 명확히 할 수 있다.
      학습 및 기술 역량 강화: 백엔드(FastAPI), 프론트엔드(React, Tailwind, TypeScript), 데이터베이스(PostgreSQL), Docker 환경 설정 등을 직접 구현하며 실무 수준의 개발 경험을 쌓을 수 있다.
  - 활용방안
      기업 및 기관의 자산 관리 시스템: IT 장비, 소모품, 주변기기 등 다양한 자산을 효율적으로 관리하고, 재고 부족·연체 반납·보증 만료 등을 사전에 예방할 수 있다. 교육 및 실습 환경: 개발 과정을 통해 배운 웹 개발, DB 관리, UI/UX 설계 등의 지식을 향후 프로젝트 또는 실무 교육에 활용할 수 있다.
      확장 가능성: 향후 모바일 앱 연동, IoT 자산 추적, AI 기반 데이터 분석 등으로 확장하여, 더욱 고도화된 자산 관리 시스템으로 발전시킬 수 있다
